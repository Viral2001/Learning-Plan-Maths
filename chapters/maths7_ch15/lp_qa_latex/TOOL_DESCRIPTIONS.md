# maths7_ch15 - tool descriptions (10 tools)

Tool Name: Pan Leveller

Tool Description:

A two-pan scale stands in the middle of the screen, with a shelf of loose objects beside it: sacks whose weight is hidden, and weights of 1, 2, 4 and 10 kg. A weight readout under each pan stays hidden until the student asks for it. The first card shows a sack and 2 kg on the left against 10 kg and 2 kg on the right, and the beam hangs level.

Before any move, the student types a guess for one sack and taps which way the beam will tip if one object comes off one pan only. Then the student drags an object off a single pan. The beam tips at once, the heavier pan is named and the message 'the pans no longer weigh the same' appears, so the student must drag the object back or do the same to the other pan. The 'same off both' button removes a chosen kind of object, such as the 2 kg weights or one sack, from both pans together, and the beam stays level with a green flash. The student keeps clearing until the sacks stand on one pan. The weights on the other pan are then shared out, one stack under each sack, and the size of one stack is the hidden weight. Only now is the typed guess compared with it.

The six cards grow harder. A sack and 2 kg against 10 kg and 2 kg gives a sack of 10 kg. Two sacks against 10 kg, 4 kg and a sack gives 14 kg once a sack comes off each pan. Five sacks against 1 kg, 10 kg, 10 kg and two sacks leaves 3 sacks against 21 kg, so a sack is 7 kg. In the fourth card 90 sacks and 50 kg face 60 sacks and 500 kg, with the sacks grouped in tens so that whole bundles can be removed; clearing 60 sacks and 50 kg leaves 30 sacks against 450 kg, so a sack is 15 kg. The fifth card is a mobile with 16 on top, a leaf, a bud and a leaf against a flower: halving 16 puts 8 on each side, so the flower is 8, and with a leaf at 3 the bud is 2. In the last card the student builds a level scale of their own that hides a 6 kg sack, and the tool checks that it is level and that the sack really is 6 kg.

Hints go in order. First: if equal weights come off both pans, does the scale stay level? Then: can you take things off until the sacks are only on one pan? Then the matching objects on both pans glow, and last the next 'same off both' move is shown, followed by a similar scale. Through doing, the student learns that a level scale stays level only when the same weight is taken from both pans, and that clearing what matches leaves the hidden weight alone to be read.

Tool Name: Stick Rule Builder

Tool Description:

A stick board shows the first positions of a matchstick pattern. Beside it sit a table with one row for each position and a column for sticks, a rule box with a line for the rule in words and a locked line for the rule in symbols, and an ask box that reads 'can it use ___ sticks?'. The first card is a row of triangles with 3, 5 and 7 sticks.

The student begins by typing a guess for how many sticks position 5 needs. Then the student builds the next positions stick by stick, dragging sticks onto the board, and every finished position fills a row of the table. A position built with the wrong number of sticks stays on the board, and the table shows it breaking the step pattern, so the student can see where the count went wrong and put it right. When each position adds the same number of sticks, the student writes the rule in words: start with 1 stick and add 2 sticks for each position. Only then does the symbols line unlock, and the student writes 2n + 1. Each table row is checked against it, and a rule that fails any built row is not accepted.

Then the ask box. The student enters 99 and the tool turns the question into the equation 2n + 1 = 99, which the student solves to get n = 49. Entering 200 gives 2n = 199, which is no whole number, so the tool answers 'no such position' and shows that the sticks run 3, 5, 7 up to 199 at position 99 and 201 at position 100, always odd. The other cards are squares with a triangle cap (6, 9 and 12 sticks, rule 3n + 3: 150 sticks is position 49, while 85 sticks gives n = 82/3, no such position), a staircase of squares (13, 22 and 31 sticks, rule 9n + 4: 85 sticks is position 9, while 150 gives n = 146/9, no such position) and a dot picture of three black blobs that each hide the same number of blue dots, with 4 dots in view and 25 in all, where the student writes 3b + 4 = 25 and finds 7 dots under each blob.

Hints go in order. First: how many sticks does each new position add to the last one? Then: fill in the table and see what stays the same. Then: the rule is the step times n plus a fixed start. Last, the rule and the ask-box equation are shown filled in, and a similar pattern follows. Through doing, the student learns that a pattern's rule, said in words and then in symbols, turns 'which position uses this many sticks?' into an equation, and that no whole-number answer means no such arrangement.

(tool id M1.S4.T4.C17.2D1, concept M1.S4.T4.C17, topic: From a Pattern to an Equation)

Tool Name: Undo Machine

Tool Description:

A machine runs across the screen from an input slot on the left, through two or three operation boxes, to an output on the right. The first card is plus 3, then times 4, then minus 5, and the output to reach is 43. Under the machine lies an empty row of boxes for the Backwards mode, and a Forwards button runs any typed input through the machine.

The student begins by typing a guess for the input, say 10, and pressing Forwards. The number travels through the boxes and 47 comes out, with a note that it is 4 too high. Another guess shows again how far off it is and in which direction, which shows that guessing and adjusting can take a while. Then the student switches to Backwards. Starting from the output 43, the student must write the inverse of the last box first, plus 5, and the number travels back to 48. Divided by 4 gives 12, and minus 3 gives 9. Each correct inverse box lights green as the number passes through it. An inverse typed in the wrong order or with the wrong operation is carried through anyway, and when the student runs the found input forwards the output does not match, with the box that caused the mismatch marked. A card counts only when the forward check returns the target.

The four cards are: plus 3, times 4, minus 5 for outputs 43 and 75, which gives inputs 9 and 17; a machine that splits the input two ways, one path times 3 and the other plus 3, and then subtracts the second result from the first, for outputs 63 and 227; two short machines, divided by 3 twice giving 5 and minus 4 twice giving -11; and the blank b in 5b - 8 = 37 drawn as a machine, times 5 then minus 8. For the split machine the student first runs 12 forwards and sees 36 on one path, 15 on the other and 21 at the end, then tries other inputs and sees that the two paths always combine to twice the input minus 3. The student undoes that single combined machine, plus 3 and then divided by 2, to find 33 and 115. The short machines give 45 and -3, undoing each division by multiplying by 3 and each subtraction by adding 4, and the last card gives b = 9, showing that solving 5b - 8 = 37 is the same job as undoing the machine.

Hints go in order. First: which box did the number leave last? Then: what undoes minus 5? Then: write the inverse under the last box and carry the output through it. Last, the whole backwards row is filled in on the first card and a similar machine follows. Through doing, the student learns that an input is found by undoing the operations one at a time in reverse order, last box first, and that running the answer forwards must give back the output.

(tool id M2.S6.T6.C37.2D1, concept M2.S6.T6.C37, topic: Trial and Error, and a Better Way)

Tool Name: Both-Sides Stepper

Tool Description:

An equation is written across a balance beam, one line per step, with a small balance icon beside every line. Under it are an operation pad with add, subtract, multiply and divide and a box for the number or term, a 'both sides' switch that is on, and a Check button. Every term wears a coloured sign tag that moves with it, so a minus is never lost. The first card is 5x - 4 = 7.

Before touching the pad, the student chooses what should go first, the term or the factor. Then the student picks an operation, add 4, and the tool writes it on both sides as a new line, 5x - 4 + 4 = 7 + 4, and tidies it to 5x = 11. Dividing both sides by 5 gives x = 11/5, and Check puts 11/5 back into the first line: 5 times 11/5 minus 4 is 7. A fraction is a fine answer when the check passes. Every new line is tested against the first, and a line that does not keep the solution says which move broke it. When the student switches 'both sides' off and applies an operation to one side only, the step is refused with the reason 'the right side did not get the same operation' and the beam tips to show why. Dividing by zero is refused with its reason.

Seven cards follow. After 5x - 4 = 7 come 11y + (-5) = 61, where the sign tags show that subtracting -5 from 61 gives 66; 6y + 7 = 4y + 21, where the student takes the smaller unknown term, 4y, off both sides first, then 7, then divides by 2, and checks that both sides of the original equation are 49; 3x - 10 = 35; 4(m + 6) - 8 = 2m - 4, where a tidy step opens the bracket and joins like terms because it only changes how the line is written; u/15 = 6, solved by multiplying both sides by 15; and x + 4 = x + 5. In the last one the student takes x off both sides, the unknown vanishes and 4 = 5 remains. The tool says there is no solution, and the student explains why: 4 more than a number and 5 more than the same number can never be equal.

Hints go in order. First: which side has the unknown, and what is stuck to it? Then: what undoes the minus 4? Then: do it to both sides. Last, the next legal line is shown. Through doing, the student learns that every line of a solution comes from the line above by one operation done to both sides, that terms are removed before factors, and that the answer is always checked in the first line.

(tool id M2.S9.T9.C55.2D1, concept M2.S9.T9.C55, topic: Solving Step by Step)

Tool Name: Term Mover

Tool Description:

Every term of an equation is a tile with a coloured plus or minus tag, and the equals sign is a line the tiles can cross. A ring can be placed around a multiplied side, and a bracket opener sits beside the equation. The first card shows 2y = 60 and -8 = 5x - 3.

To move a term, the student first taps the sign it will have on the other side, then drags the tile across. The tag flips colour as it crosses, and the tool re-checks that the solution is still the same. In -8 = 5x - 3 the student drags -3 across as +3, giving -8 + 3 = 5x, so 5x = -5. A term dropped across with its old sign is refused with the reason 'this term was added on the left, so it must be taken away on the right'. For a factor, the student drags the ring around 5 to the other side, and the whole other side is divided: x = -5 divided by 5, which is -1. A ring dragged over one term only is refused with 'divide the whole side'. The same ring takes a divisor across by multiplying the whole other side, so u/15 = 6 becomes u = 6 times 15. Tapping the bracket opener multiplies every term inside, so 5(r + 2) becomes 5r + 10, and a bracket opened on the first term only is shown with the second product missing.

Seven pairs of equations come first: 2y = 60 and -8 = 5x - 3; -53w = -15 and 13 - z = 8; k + 8 = 12 - k and 7m = m - 3, where the unknown terms must meet on one side; 5(r + 2) = 10 and -3(u + 2) = 2(u - 1); 2(7 - 2n) = -6 and 2(x - 4) = -16; 6(x - 1) = 2(x - 1) - 4 and 3 - 7s = 7 - 3s; and 2x + 1 = 6 - (2x - 3) and 10 - 5x = 3(x - 4) - 2(x - 7). The last card is a path board of twelve equation boxes. The start box, 8x = 20 + 3x, is already solved as x = 4. The student solves each box with legal moves only and follows the arrow that carries its answer to the next box: 4 leads to 2x - 9 = -3, which gives 3, and so on until an arrow reaches End.

Hints go in order. First: what was done to this term on its own side? Then: what takes it away on the other side? Then the tile and its sign glow. Last, the move is shown and a similar equation follows. Through doing, the student learns that moving across is the same balance move written in one line: a term changes its sign, a factor divides the whole other side, a divisor multiplies it, and brackets are opened first.

(tool id M2.S12.T12.C67.2D1, concept M2.S12.T12.C67, topic: The Shortcut: Moving Across)

Tool Name: Story to Equation Board

Tool Description:

A short story sits at the top of the board. Below it are a 'let the letter be' box, a small table of values, an equation box marked step 1, and a solving area marked step 2 that stays locked at first. The first story is Ranju, a daily wage labourer paid 750 rupees a day in an equal number of 50 and 100 rupee notes.

Before writing anything, the student types a rough guess. Then the student names the unknown and says what it counts, for example n is the number of notes of each kind. The table of values lets the student test numbers against the story: n = 4 gives 4 times 50 plus 4 times 100, which is 600, too low, and n = 6 gives 900, too high. The student writes 50n + 100n = 750, and step 1 is graded on its own by testing the equation against the story. An equation that reverses the story is not corrected. In the juice story, j = 15 - m puts a negative price in the table, and step 1 stays open until the equation fits. Once it does, step 2 opens, and the student solves 150n = 750 to get n = 5, marked separately. The story check reads the answer back in words: 5 notes of each kind make 250 plus 500, which is 750.

The seven stories are Ranju's notes; a taxi with 800 rupees fixed plus 20 rupees for each km and 2200 in all (800 + 20k = 2200, k = 70); two numbers adding to 76 where one is three times the other, written t and 3t (19 and 57); a window grill 34 cm tall with 3 cm borders, 5 rods 2 cm thick and 6 equal gaps (3 + 3 + 5 times 2 + 6g = 34, g = 3); a juice 15 rupees cheaper than a milkshake, where 4 juices and 7 milkshakes cost 600 (4(m - 15) + 7m = 600, so milkshake 60 and juice 45); the angles of two triangles that add to 180 degrees (y + 2(y + 15) = 180, and x + (x - 10) + (x + 10) = 180); and 28 heads and 80 feet on a beach, with d donkeys and 28 - d children (4d + 2(28 - d) = 80, so 12 donkeys and 16 children). With two unknowns, the student writes the second using the first, then finds it after solving.

Hints go in order. First: what does the letter count? Then: say the story as a fixed amount and a changing amount. Then: try a number in the table and compare it with the total. Last, the shape of the equation is shown with blanks. Through doing, the student learns to set up and solve as two separate steps, to write one unknown using the other, and to check the answer in the story, not only in the equation.

(tool id M3.S14.T14.C82.2D1, concept M3.S14.T14.C82, topic: Everyday Problems as Equations)

Tool Name: Trick Tracer

Tool Description:

A number trick is laid out as a list of steps down the left of the screen. Beside every step are two columns: a number column for a number the student tries, and a letter column that holds the expression so far. Under them are an 'equals the result' bar and a solver area. The first trick is Riyaz's: think of a number, subtract 3, multiply by 4, add 8, and Akash's final answer is 24.

The student first guesses the starting number from 24. Then the student runs the steps with two different numbers: starting at 5 gives 2, 8, 16, and starting at 10 gives 7, 28, 36. Next the student fills the letter column from x: x - 3, then 4(x - 3), which becomes 4x - 12, then 4x - 4. The two columns must agree for every tried number. An expression that does not match is flagged at the first step where they differ, with both values shown: writing 4x - 3 for the multiply step gives 17 where the number column has 8 for a start of 5. The student then sets the last expression equal to the result, 4x - 4 = 24, and solves it: 4x = 28, so x = 7. The found number is run through the steps as a final check, 7 giving 4, 16 and 24. The student also sees that every tried number ends at 4 times (start minus 1), so the trick can be undone by dividing the answer by 4 and adding 1.

The other four cards are puzzles, where a list of clues replaces the steps and the number column tests a tried number against the clue. A three-digit number has a hundreds digit 3 less than the tens digit, a tens digit 3 less than the units digit and a digit sum of 15: with units digit u the digits are u - 6, u - 3 and u, so 3u - 9 = 15 and the number is 258, while a units digit of 9 gives a sum of 18, too much. A brick weighs 1 kg more than half its weight, so w = w/2 + 1, and 'half its weight' is shown as w/2, not 2w, with a test number such as 6 to show the difference; taking w/2 off both sides leaves w = 2. A giraffe is two and a half metres more than half its height, so h = h/2 + 2.5 and h = 5 m. The last card has two puzzles: a quarter of a number increased by 9 gives the number, q/4 + 9 = q, so q = 12; and a number increased by 36 is ten times itself, a + 36 = 10a, so a = 4.

Hints go in order. First: what happens to the number in the first step? Then: do the same step to the letter x. Then: compare your letter column with the number column. Last, the expressions are shown for the first trick and a similar puzzle follows. Through doing, the student learns that writing each step with a letter turns a trick or a puzzle into an equation, because the last expression equals the answer, and that solving it undoes the steps.

(tool id M3.S17.T17.C103.2D1, concept M3.S17.T17.C103, topic: Many Roads to One Answer)

Tool Name: Chain Maker

Tool Description:

The chain starts from a single card, x = -2, at the top of the board. Below it are an operation pad for adding, subtracting, multiplying or dividing both sides by a number, and a reverse button. Each new equation hangs below the last as a link in the chain, every term carrying a sign tag, with a tick beside the link when the starting value makes it true.

Before adding a link, the student says what the solution of the new equation will be. Then the student presses an operation, say add 2 to both sides, and the link x + 2 = 0 appears with a tick. Multiplying by 3 gives 3x = -6, and the student carries on until five equations have the solution -2, such as x + 2 = 0, 3x = -6, x - 1 = -3, 2x + 5 = 1 and -x = 2. A link made by changing one side only is added but marked false for the starting value, and the chain breaks visibly at that link, so the student sees why the same operation must be done to both sides. The second card does the same from u = 6 and asks for four equations, for example u + 4 = 10, 5u = 30, u/2 = 3 and 3u - 8 = 10.

In the third and fourth cards the student reads related expressions straight from a given equation. From 4k + 1 = 13 the tool asks for 8k + 2, 4k, k, 4k - 1 and -k - 2. The student predicts 8k + 2 as twice the left side, which is 26, and the tool shows it as 2 times (4k + 1), then confirms it with k = 3. In the same way 4k is 12, 4k - 1 is 11 and -k - 2 is -5. From 28p - 36 = 98 the student finds 14p - 19, which is 48 (halve both sides, then take 1 more away), and 28p - 38, which is 96 (take 2 more away). The last card runs a chain the other way. The chain 3y = 15, add 6, divide by 3, subtract 2 reaches y = 5. The student presses reverse and names the inverse of each operation going up: add 2, multiply by 3 and subtract 6.

Hints go in order. First: if the same thing is done to both sides, does the answer change? Then: which link first turned false? Then: undo the last operation first. Last, a finished chain is shown and the student builds a different one. Through doing, the student learns that starting from the solution and doing the same operation to both sides gives endless equations with the same solution, that going up undoes going down, and that a related expression can be read from an equation without solving it.

(tool id M3.S20.T20.C122.2D1, concept M3.S20.T20.C122, topic: Making Equations from an Answer)

Tool Name: Step Detective

Tool Description:

A finished solution is written one line per row, with a sign tag on every term, and the student is the detective. Beside it are a test value box and a 'test line' button, and below it a mend area. The first case is 4(4q + 2) = 50, solved as 4(4q) = 50 - 2, then 16q = 48, then q = 3.

Before testing, the student taps the line they think is broken, or 'no mistake'. Then the student puts the final answer q = 3 into the first line: 4 times (12 + 2) is 56, not 50, so something is wrong. Pressing 'test line' down the rows shows that q = 3 fits line 2 but not line 1, and the first line whose solution differs from the line above is highlighted. The student names the broken move from a short list: sign kept, part divided, bracket half-opened, upside-down division, unlike terms added, and a wrong sign in a product. Here it is a half-opened bracket, because the 2 inside is also multiplied by 4, so the term to move is 8. The named move is checked against the actual break. Then the student rewrites the line as 16q + 8 = 50 and finishes with 16q = 42 and q = 21/8. A mended line that is still illegal is not accepted; the tool shows its solution beside the first line's and asks for another try.

The cases are 4(4q + 2) = 50; -2(3 - 4x) = 14, where -6 - 8x = 14 wrote -2 times -4x as -8x instead of +8x (x = 5/2); 3(7y + 4) = 9 + 5y, with two breaks, 5y not divided by 3 and later a 4 that kept its sign (y = -3/16); 6x + 9 = 66 turned into x + 9 = 11, a part-divided side (x = 19/2); 14y + 24 = 36 solved as 7y + 12 = 18, 7y = 6, y = 6/7, which has no mistake because y = 6/7 fits every line, and 'no mistake' is accepted only when every line keeps the solution; and 4x - 5 = 9x + 8, where the -5 kept its sign and the last division is upside down (-5x = 13, x = -13/5). In the last case the student breaks a solution on purpose for a friend: a solved equation is copied, one line is changed, and the tool confirms the change really breaks the solution and asks the student to name the move.

Hints go in order. First: put the final answer back into the first line. Then: test each line, does it keep the solution of the line above? Then: what was done to the left side, and was exactly the same done to the right? Last, the broken line is highlighted and a similar solution follows. Through doing, the student learns to test a solution instead of trusting it, to find the one line where the solution changes, and to name the move that broke it.

(tool id M3.S23.T23.C137.2D1, concept M3.S23.T23.C137, topic: Mind the Mistake, Mend the Mistake)

Tool Name: Rule of Four Numbers

Tool Description:

Brahmagupta's rule is built by hand on an equation card. The card shows 5x + 4 = 3x + 8 with its four plain numbers coloured: A = 5 and C = 3 sit beside the unknown, B = 4 and D = 8 stand alone. Below are empty slots arranged as x = (D - B) / (A - C), a side panel that solves the same equation by balance moves, and a sharing panel for an old problem.

Before using the rule, the student guesses whether x will be positive or negative. Then the student drags the coloured numbers into the slots, minding their signs; the colours stay the same from card to rule, so each number is easy to find. The rule gives (8 - 4) / (5 - 3) = 2, and the answer is checked in the equation, 14 on both sides. In the side panel, 3x and 4 come off both sides, 5x - 3x = 8 - 4, and the two answers match. When B is negative, as in 3x - 6 = 2x + 4, the slot shows D - (-6), not D - 6, and the rule gives (4 - (-6)) / (3 - 2) = 10. A number dropped into the wrong slot is kept there and the side panel shows the two answers disagreeing, so the student can see that a slip has happened.

The next cards are 650m + 4000 = 500m + 5050, giving m = (5050 - 4000) / (650 - 500) = 1050 / 150 = 7, the months Jahnavi and Sunita need to have equal savings; and 2x + 3 = 4x + 5, where D - B = 2 and A - C = -2, so x = -1, a negative answer the student can predict from the signs. The fifth card is 3x + 2 = 3x + 7. Here A = C, so A - C = 0, and the tool says 'dividing by zero is not allowed' and gives the reason. The balance panel takes 3x off both sides and leaves 2 = 7, which is never true, so the equation has no solution. In the sharing panel, a problem from the Bakhshali manuscript shares 132 among four people: the first gets a, the second twice as much, the third three times the second and the fourth four times the third. The student writes a + 2a + 6a + 24a = 132, gets 33a = 132 and a = 4, and checks that the shares 4, 8, 24 and 96 add to 132.

Hints go in order. First: which two numbers go with x, and which stand alone? Then: D minus B goes on top and A minus C below. Then: take care with the sign of B. Last, the rule is shown with the colours filled in. Through doing, the student learns that for any equation of the form Ax + B = Cx + D with A and C different, one rule gives the same answer as the balance moves, and that the rule cannot work when A and C are equal.

(tool id M4.S25.T25.C161.2D1, concept M4.S25.T25.C161, topic: A Pinch of History)
