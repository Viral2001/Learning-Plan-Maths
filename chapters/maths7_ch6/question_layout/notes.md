The icon alone is not decisive (the opener "What do you think these numbers mean?" and "Add a few even numbers together" carry it too and are discussion). I counted an item when it has a definite answer AND the plan holds a worked-example block with that question, steps and answer. The chapter prints no "Example N": the "Example 1:" labels on plan blocks are the plan's own numbering inside each teaching concept, so there is no example tier here. The plan tags no block with a ref, so the plan ref used for each new question is the coverage id of its concept that names the same item.
