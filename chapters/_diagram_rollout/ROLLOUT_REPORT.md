## Your five answers that shaped the result
1. Book print slips: diagrams show the CORRECTED value (e.g. Class 6 Ch 10 grid -17, Class 7 Ch 13 boys' median 143.5, Class 7 Ch 3 ruler 8 9/10).
2. LP text mistakes or missing data: left untouched, listed in ROLLOUT_AGENT_NOTES.md under 'LP text issues' for the content team.
3. Figure letters (a), (b)... shown only where the LP answer refers to them by letter.
4. Borderline 'required' calls kept as the agents made them (listed in ROLLOUT_AGENT_NOTES.md).
5. Teaching images: an item that needs a figure gets its OWN diagram even if a kept teaching image shows it (audited for every chapter; corrective versions uploaded where an item flipped).
